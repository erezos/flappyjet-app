## 🎯 KEY DESIGN PRINCIPLES:

### **1. Variety Rhythm:**
```
Never more than 2 obstacle levels in a row
Time levels break up monotony
VS levels every 5th = predictable excitement
```

### **2. Difficulty Sawtooth:**
```
Build tension → Boss → Relief → Build → Boss
Each zone ends with hardest level
Post-boss levels are slightly easier
```

### **3. Corridor Mastery:**
```
L2: "Oh, there are lots of obstacles!"
L14: "I see the corridor pattern!"
L28: "This is an extreme snake path!"
L48: "INSANE! Obstacles everywhere!"
```

### **4. Bot Evolution:**
```
Early: Friendly sparring partner
Mid: Challenging rival
Late: Nightmare opponent
L50: LEGENDARY final battle
```
